Глава 1

Архитектура Эффективной Модели

Прежде чем писать формулы, профессионал проектирует структуру. Ошибка в архитектуре на старте приведет к краху всей модели при масштабировании.

«Планирование без структуры — это галлюцинация. Структура данных определяет успех анализа.»

— Принцип Database Design

Золотые правила Flat Data

  • Одна строка — одна запись. Никаких объединенных ячеек или пустых строк для "красоты".
  • Один столбец — один тип данных. Не смешивайте даты и текст в одном столбце.
  • Разделение данных и расчетов. Исходники (Raw Data) должны жить на отдельных листах, которые скрыты и защищены.

Диспетчер Имен (Name Manager)

Профессионалы редко используют адреса ячеек (A1, B2) в сложных формулах. Они дают диапазонам понятные имена.

Best Practice Вместо: =SUM(Sheet2!A2:A5000) Используйте: =SUM(Sales_Amount)
Глава 2

Динамические Массивы (Office 365)

Это самый большой прорыв в Excel за последние 10 лет. Формулы больше не живут в одной ячейке — они могут возвращать целые таблицы.

Функция FILTER

Заменяет сложные сводные таблицы и макросы фильтрации. Работает мгновенно даже на больших объемах.

Formula =FILTER(A2:D1000; (C2:C1000="IT") * (D2:D1000>100000); "Не найдено")

Комбинация SORT + UNIQUE

Позволяет создавать динамические выпадающие списки, которые обновляются сами при добавлении новых данных.

Formula =SORT(UNIQUE(B2:B500))

Оператор Spill (#)

Если вы видите ошибку #SPILL!, значит, формуле некуда "разливаться". Убедитесь, что диапазон ниже чист.

Глава 3

Power Query: ETL Процесс

Extract, Transform, Load. Если вы тратите более 15 минут в день на копирование и очистку данных, вам срочно нужен Power Query.

Ключевые возможности

Инструмент Применение
Unpivot Превращает "шахматную" таблицу отчета в плоскую базу для анализа.
Merge Queries Аналог ВПР (VLOOKUP), но работает быстрее и не тормозит файл.
Append Объединение таблиц с одинаковой структурой (например, отчеты по месяцам).

«Никогда не меняйте исходные данные вручную. Запишите шаг в Power Query, и он будет повторяться вечно.»

— Манифест автоматизации

Глава 4

Модель Данных и DAX

Когда данных становится больше 1 миллиона строк, обычный Excel сдается. Power Pivot позволяет загружать данные в память и сжимать их в 10 раз.

Контекст Вычислений

В DAX результат формулы зависит от того, какие фильтры наложены на таблицу в данный момент (срезы, строки сводной).

Топ функций DAX

DAX Measure // Расчет продаж за прошлый год Sales LY := CALCULATE( [Total Sales]; SAMEPERIODLASTYEAR('Calendar'[Date]) )
DAX Measure // Доля в категории % of Category := DIVIDE( [Total Sales]; CALCULATE([Total Sales]; ALL('Product'[Category])) )
Глава 5

VBA: Высший Пилотаж

Макросы нужны там, где бессильны формулы: взаимодействие с Outlook, Word, создание PDF, сложная логика интерфейса.

Структура профессионального макроса

VBA Code Sub GenerateMonthlyReport() Dim ws As Worksheet Dim wb As Workbook ' Отключаем обновление экрана для скорости Application.ScreenUpdating = False Set wb = Workbooks.Add Set ws = wb.Sheets(1) ' Копируем данные ThisWorkbook.Sheets("Data").Range("A1").CurrentRegion.Copy _ Destination:=ws.Range("A1") ' Сохраняем как PDF ws.ExportAsFixedFormat Type:=xlTypePDF, _ Filename:="C:\Reports\Oct.pdf" Application.ScreenUpdating = True MsgBox "Отчет готов!", vbInformation End Sub

Безопасность

Всегда используйте Option Explicit в начале модуля, чтобы избегать ошибок в названиях переменных.

Глава 6

Оптимизация и Аудит

Медленная таблица раздражает. Профессионал знает, как ускорить расчеты в 100 раз.

Чек-лист оптимизации

  • Избегайте целостолбцовых ссылок. Не пишите =SUM(A:A), если в столбце 1 млн пустых ячеек. Указывайте точный диапазон или используйте Таблицы (Ctrl+T).
  • Отключите пересчет. При работе с тяжелыми макросами ставьте Application.Calculation = xlManual.
  • Используйте бинарный формат. Сохраняйте файлы как .xlsb. Они весят меньше и открываются быстрее.
  • Убирайте условное форматирование. Оно сильно грузит процессор при прокрутке.

«Совершенство достигается не тогда, когда уже ничего не добавить, а когда уже ничего нельзя убрать.»

— Антуан де Сент-Экзюпери
